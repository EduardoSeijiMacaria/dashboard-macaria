Vue 3 single-page app that audits GitHub issues against consistency rules. It runs fully in the browser. It has no backend. This directory holds the project setup, the HTML shell, and the `src/` and `tests/` folders.

## Summary

- README.md — `.env` setup, token warning, data source, implemented features, and pending decisions (in Portuguese)
- .env.example — the three variable names (`GIT_TOKEN`, `REPOSITORY_URL`, `PROJECT_NUMBER`) with empty values; the real `.env` is git-ignored
- index.html — Vite HTML shell that loads `src/main.ts`
- package.json — scripts (`dev`, `build`, `test`, `format`, `format:check`) and dependencies (Vue, Vite, Vitest, vue-tsc, Prettier)
- package-lock.json — locked dependency versions
- vite.config.ts — sets the base path to `./` when `GITHUB_PAGES=true`, otherwise `/`; embeds only `GIT_TOKEN`, `REPOSITORY_URL`, and `PROJECT_NUMBER` from `.env` through `define`; under Vitest (mode `test`) all three are empty strings
- .prettierrc.json — Prettier settings: 2 spaces, 100 columns, no semicolons, single quotes
- .prettierignore — files Prettier skips: dependencies, build output, generated files, agent folders, Markdown
- tsconfig.json — type-check settings for `src/` and `tests/`
- tsconfig.node.json — type-check settings for `vite.config.ts`
- tsconfig.tsbuildinfo — generated TypeScript build cache (git-ignored)
- .gitignore — ignores `.env`, `.env.local`, `node_modules/`, `dist/`, `*.tsbuildinfo`, `docs/internal/`, `.agents/`, `.memory/`, and editor files
- docs/ — `FEATURE-MAP.md` (the feature index, committed) and `internal/` (git-ignored: the project specification and the refactoring prompt)
- src/ — application source
- tests/ — Vitest test files
- dist/ — generated build output, git-ignored (not documented)
- node_modules/ — installed packages (not documented)

## Constraints

- The app MUST run without a server. The browser calls `api.github.com` directly.
- `dist/` embeds the GitHub token. It MUST NOT be hosted publicly.
- `.env` MUST stay out of version control and out of logs and output.
