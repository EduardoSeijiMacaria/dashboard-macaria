Holds `useAuditDashboard.ts`, the state container for the dashboard screen, with `useIssueFilters.ts` for its filter part, and `useTheme.ts`, the light and dark theme state. `useAuditDashboard` owns the refs for filters, issues, findings, history runs, and sync status. It exposes the filtered lists and metrics as computed values. The filter and metric logic lives in pure functions under `services/`.

## Summary

- useAuditDashboard.ts — state, computed views, and actions: GitHub sync (runs on page open), update of the selected issue (one GET plus the Project item, then in-memory re-evaluation with no saved run; cancellable; a Project failure fails the update); `connectionStatus` is `checking`, `connected`, or `disconnected`; `issueUpdateStatus`, `syncFailure`, and `projectFailure` hold a message key with its data (`MessageRef`), never a translated text
- useIssueFilters.ts — the `filters` ref and the computed values built from it: assignees, filtered issues, filtered findings, and metrics
- useCurrentPage.ts — `readPageFromHash` and `useCurrentPage`: the open page (dashboard or About) from the URL hash
- useLocale.ts — `initializeLocale` (saved choice, else the browser language, else `pt-BR`; sets the `lang` attribute and the page title) and `useLocale` (`changeLocale` switches at once, saves the choice in `localStorage`, and makes no request)
- useTheme.ts — resolves the theme from the saved choice or the system setting, sets `data-theme` on the page root (with a short `theme-changing` class that fades the colors; off under reduced motion), and saves the choice in `localStorage`

## Constraints

- The GitHub token comes from the build (`.env`). It MUST NOT go to storage, to a log, or to a message.
- A new sync MUST clear the previous issues and findings first. The table MUST NOT show stale rows.
- A sync and a single-issue update MUST NOT run together. An update MUST NOT change a selection the user moved.
- Every `localStorage` read and write MUST sit in try/catch. The page MUST work when storage is blocked.
- The storage key and the saved-value check in `useTheme.ts` MUST match the inline script in `index.html`.
