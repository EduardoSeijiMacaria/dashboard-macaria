Vue components that make up the dashboard screen. Each one has one job and receives data through props. Only `DashboardView.vue` talks to the composable.

## Summary

- SeverityBadge.vue — badge for a severity (error, warning, info): hidden icon and a visible Portuguese label (or a given label such as a count), so color is never the only signal
- ThemeToggle.vue — icon-only button (sun in the dark theme, moon in the light theme) whose accessible name states the switch action; emits `toggle`
- LanguageSwitch.vue — group of three buttons (PT, EN, ES) with `aria-pressed` on the active one; each button is named in its own language and emits `change`
- AppIcon.vue — inline SVG icons by name (settings, database, alert, filter, list, shield, user, sun, moon); decorative, hidden from screen readers
- AppHeader.vue — page header (also holds the language switch): "Macaria QA" (link to the dashboard), "Dashboard" and "Sobre" links with the current page marked, a connection text (`Conectando`, `Conectado`, or `Desconectado`), the theme toggle, and the "Configurações" button (gear icon; the text hides on small screens)
- AppFooter.vue — page footer: a discreet text and the "Abrir repositório no GitHub" link (only when the repository URL is known)
- SettingsPanel.vue — the "Configurações" side panel, a native `<dialog>`: organization, repository, Project, token state (never the value), the Project failure reason, and where the values come from; closes with Escape, the close button, or the backdrop
- ConnectionSummary.vue — one compact line with the organization, repository, and Project, shown above the filters once a connection is known
- FilterBar.vue — labeled filters (search, assignee, issue type, severity, situation, period) bound with `v-model` to `Filters`
- RefreshControl.vue — "Atualizar análise" button, "Cancelar" while busy, and the last update time
- SummaryBar.vue — three counts: issues analyzed, issues with problems, findings
- StateMessage.vue — loading, error, and empty messages with the right ARIA role
- IssueTable.vue — issue rows (number, title, assignee, Project status, problems) and a `details` slot under the open row
- IssueDetails.vue — findings table (field, current value, expected pattern, explanation), checks that could not run, GitHub link, and "Atualizar esta issue"

## Constraints

- The interface MUST NOT show rule IDs such as `TASK-001`. A finding appears by its real field name and a message.
- Components MUST render issue text through interpolation, never `v-html`.
- A state MUST show text or an icon, not only color.
- A component MUST NOT show the token, an issue ID, or an API detail.
