Application source for the audit dashboard. `main.ts` mounts `App.vue`, which renders `views/DashboardView.vue`. State and actions live in `composables/`. Pure audit logic lives in `rules/`. Side-effect code lives in `services/`.

## Summary

- main.ts — picks the language, creates the Vue app, mounts it on `#app`, imports global styles
- i18n/ — the three message catalogs and the translation helpers
- App.vue — root component; renders the dashboard view
- env.d.ts — type declarations for the three build-time values `__GIT_TOKEN__`, `__REPOSITORY_URL__`, and `__PROJECT_NUMBER__`
- style.css — color tokens (light and dark), base elements, buttons, inputs, and the shared badge and spinner
- components/ — the dashboard building blocks
- composables/ — dashboard state and actions
- rules/ — audit rule engine
- services/ — default config, sync settings, date helpers, audit state, GitHub client
- types/ — shared domain types
- views/ — the single dashboard screen
