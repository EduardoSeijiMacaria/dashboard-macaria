Rule families that check one kind of issue each. `taskRules.ts` runs for tasks. `subtaskRules.ts` runs for subtasks. `fieldRules.ts` runs for every issue. Its sibling check (FF-003) runs in a second pass from `engine.ts`.

## Summary

- taskRules.ts — TASK-001 title format, TASK-002 end date, TASK-004 required subtasks, TASK-005 all subtasks complete
- milestoneRules.ts — MILESTONE-001: the issue needs a milestone, and it must be one of the allowed names from the config
- requiredFieldRules.ts — FIELD-001 empty required Project field (one finding per field, with its own message), FIELD-002 Start when the Status is not Todo
- subtaskRules.ts — SUB-001 marker, SUB-002 spacing, SUB-003 plural "Scenarios", SUB-004 title format
- fieldRules.ts — FF-001 feature flag missing, FF-002 flag conflicts with "No FF", FF-003 sibling flag divergence

## Guidance

- A new rule family SHOULD get its own file here. Call it from `engine.ts`.
